## Architecture Summary

See `/Users/ethancls/Kyle/docs/memory/architecture.md` for the full spec.

### Data Flow (simplified)

```
Traefik → Go Agent (:5001) → Next.js Dashboard (:3000)
                │                      │
                │  [ensureRecentSync]  │
                │  (coalesced, TTL 3s) │
                └──────→ SQLite ←──────┘
                       (kyle.db)
```

### Key Design Decisions

1. **Coalesced sync** — `lib/agent.ts:ensureRecentSync()` prevents duplicate agent fetches. Only one HTTP call in flight at a time. Called only from the Dashboard server component. API routes are pure SQLite readers.

2. **Live vs History separation** — `/api/logs` returns live agent data. `/api/logs/history` returns paginated SQLite data. `LogsClient` has a toggle between modes.

3. **SQLite deduplication** — `INSERT OR IGNORE` with `dedup_key` unique index prevents duplicate log entries.

4. **Geo map** — `GET /api/stats/geo` resolves real traffic by country via ip-api.com with server-side caching.

5. **Real time series** — `GROUP BY strftime('%H')` in SQLite powers the 24h hourly charts in the dashboard stat drawers. No more fake data.

6. **Agent port change** — Moved from 5000 to 5001 because macOS Sonoma/Sequoia binds AirPlay Receiver on :5000 via ControlCenter.

## Key Reminders

- **Port 5000 is blocked by macOS AirPlay** — always use 5001 for the agent
- **OrbStack must be running** for Docker, Traefik, and all services
- **No more `syncLogs()`** — the old function is fully removed. Use `ensureRecentSync()` from `lib/agent.ts`
- **Never call the agent from the browser** — all agent communication goes through Next.js API routes
- **UI components live in `@kyle/ui`** — use `Input`, `Select`, `Badge`, `EmptyState`, `ErrorBanner`, `Panel` instead of raw Tailwind chains
- **Shared types in `@kyle/shared`** — `FirewallEntry`, `ServiceInfo`, `AnalyticsData`, `LogEntry`
